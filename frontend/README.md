# Frontend — Web UI (Single-Page App)

This folder contains the Kisan Setu web interface.

## Contents
- `index.html` — Main SPA entry point
- `app.html` — Alternative UI layout
- `static/` — Static pages (process flows, mockups)

## Running
Start the backend server (see `backend/README.md`) and open `http://localhost:8080` in your browser.
