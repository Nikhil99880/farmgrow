# Mobile — Flutter App

This folder contains the Kisan Setu farmer mobile application built with Flutter.

## Contents
- `kisan_setu_app/` — Flutter project
  - `pubspec.yaml` — Dependencies
  - `lib/` — Dart source code
  - `web/` — Web build (optional)

## Building
```bash
cd kisan_setu_app
flutter pub get
flutter run
```

## Architecture
Connects to backend APIs at `http://localhost:8080` (or production endpoint).
