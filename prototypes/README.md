# Prototypes — UI/UX Mockups

This folder contains Figma-exported HTML screens and design prototypes for the Kisan Setu platform.

## Contents
- `stitch_kisan_rural_connect/` — Screen prototypes
  - `login/` — Login & OTP flows
  - `registration/` — Farmer registration
  - `book_slot_*/` — Slot booking flows
  - `dashboard/` — Farmer dashboard
  - `live_tracker/` — Queue tracking
  - `my_payments/` — Payment history
  - `mandi_token/` — Token screens
  - And more...

## Usage
Open any `.html` file in a web browser to see the design prototype.
